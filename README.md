# NLP Spam Detection Project

## 📌 Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify SMS messages as Spam or Ham (Normal Message).

## 🎯 Objective
The main objective is to identify unwanted or suspicious messages using text classification techniques.

## 📂 Dataset
- Dataset: SMS Spam Collection Dataset
- Source: Kaggle
- Link: https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- NLP
- TF-IDF
- Logistic Regression
- Google Colab

## ⚙️ Project Workflow
1. Load the CSV dataset
2. Clean and preprocess the messages
3. Explore the dataset
4. Convert text into numerical features using TF-IDF
5. Split the data into training and testing sets
6. Train a Logistic Regression model
7. Evaluate model performance
8. Predict new messages

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## 💡 Example Predictions
**Input:** Congratulations! You won a free prize. Click now!

**Output:** Spam

**Input:** Hi, how are you? Shall we meet today?

**Output:** Ham (Normal Message)

## 🚀 How to Run
1. Download or clone this repository.
2. Open the notebook in Google Colab.
3. Upload the dataset CSV file.
4. Run all code cells.
5. Test the model using new messages.
